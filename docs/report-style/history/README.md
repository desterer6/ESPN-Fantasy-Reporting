# Season history, Weeks 1-7 (recovered facts)

These are fact sheets recovered from David's older report conversations. **They aren't his
published wording.** Use them for storylines and callbacks ("remember when Clonch lost by 0.10 in
Week 1"), and never quote them as his original text. Only Weeks 8-9 recaps exist verbatim (see
[../examples/](../examples/)).

| File | Contents |
|---|---|
| `fayettevilles-finest/week-0N-recovered-facts.md` | Results, standings notes, rankings and next-week preview facts for each week |
| `yellowstone/week-0N-recovered-facts.md` | Same for Yellowstone |
| `matchup-results-weeks-01-07.csv` | Every recovered score |
| `power-rankings-weeks-01-09.csv` | Every recovered ranking and tier label (Weeks 1-6 used older formulas, not Option B) |
| `matchups-to-watch-weeks-01-07.csv` | Every recovered matchup-to-watch pick |
| `RECOVERY_INDEX_original.md` | The recovery index that came with the archive |

## Checked against the live league data

Every recovered score was matched against the Sleeper and ESPN data in the site files. All of them
line up except one: **Yellowstone Week 7, Team abart28 beat FELONS 88.98-83.82**, not 87.98. The
league data wins whenever the two disagree, so pull facts from `scripts/week-facts.mjs` first.

Matching scores also confirmed which old team names belong to which franchise. That map is in
[../leagues.md](../leagues.md#team-name-history).
